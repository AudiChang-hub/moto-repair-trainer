# 機車維修訓練場

給零基礎學習者的互動式維修模擬系統(燃油機車 + 電動機車)。純網頁、離線、不用安裝。

## 線上版(手機 / 平板 / 任何電腦)

**https://audichang-hub.github.io/moto-repair-trainer/**

- **iPhone / iPad(Safari)**:開啟網址 → 分享按鈕 → 「加入主畫面」。
- **Android(Chrome)**:開啟網址 → 右上角 ⋮ → 「安裝應用程式」或「加到主畫面」。
- 第一次開啟後會自動把全部內容存進裝置,**之後沒有網路也能用**。
- 各裝置的學習進度不會自動同步:用側邊欄「📦 備份 / 換裝置」匯出/匯入。
- 更新方式:修改後執行 `node tools/gen-sw.js`,`git push` 到 main,約一分鐘後線上版自動更新(GitHub Pages)。

## 開啟方式(本機)

**雙擊 `index.html`** 即可(Chrome / Edge 皆可)。學習進度存在瀏覽器的 localStorage,**換瀏覽器或清除網站資料會重置**。

## 考照題庫的來源與可信度

- 題目與答案取自勞動部勞動力發展署技能檢定中心公開的「學科測試參考資料」:丙級 `145003A13`(版次 V114090113)、乙級 `145002A12`。依《著作權法》第 9 條,依法令舉行之考試試題不受著作權保護。
- 做法:**官方答案**從 PDF 文字層直接取出;**中文題幹與選項**由 AI 逐頁看圖轉錄,並**逐題與官方答案核對**(丙級 599 題、乙級 716 題,答案全部一致、無缺題);圖題裁切自原 PDF。
- **白話解析**是 AI 輔助撰寫的,可能有錯。解析沒把握的題目標有「解析待確認」(丙級 43 題、乙級 102 題),原因沒把握的只寫「這題要記」。**一切以官方答案為準。**
- 題庫可能隨官方改版而過期,請定期到[技能檢定中心](https://www.wdasec.gov.tw/)確認最新版本。

## 設計與品質

- 設計系統:暖白紙張/深炭灰,安全橘為唯一強調色;支援淺色、深色、跟隨系統,並尊重「減少動態效果」設定。
- 圖示:[Lucide](https://lucide.dev)(ISC 授權,`js/icons.js` 檔頭附授權全文);介面上的 emoji 會自動轉成對應線條圖示。
- 無障礙:跳到主要內容連結、鍵盤可操作、換頁焦點管理、`aria-current`、觸控目標 ≥ 44px。
- Lighthouse(線上版,2026-10-02):手機 效能 99 / 無障礙 100 / 最佳實務 100 / SEO 100;桌機 四項皆 100。

## 多裝置使用(手機 / 平板)

- 部署成網站後(見上方「線上版」),可在手機「加到主畫面」安裝成 App,並**離線使用**(Service Worker 會快取全部內容)。
- 學習進度存在各裝置的瀏覽器,**不會自動同步**。到「📦 備份 / 換裝置」匯出進度代碼或檔案,在另一台匯入即可(支援合併)。
- 新增或修改檔案後,執行 `node tools/gen-sw.js` 重新產生離線快取清單。

```

```

## 如何新增內容

所有內容都是 `js/data/` 下的純資料,不需要改程式。

- **診斷案例**(`scenarios.js`):複製一個案例,改 `tests`。每個檢查的 `v` 是評分依據:
  `key` 關鍵檢查 / `ok` 合理檢查 / `waste` 浪費 / `bad` 危險或錯誤操作。
  `causes` 放候選原因、`answer` 是正解 id、`fixes` 中只有一個 `ok: true`。
- **流程演練**(`procedures.js`):每個 `step` 的 `options` 只有一個 `ok: true`,並寫好每個選項的 `why`。
- **教材**(`lessons.js`):`blocks` 支援 `p h list ol analogy warn tip key table widget link`。
- **術語**(`glossary.js`)、**零件**(`parts.js`)、**課表**(`plan.js`)同理。

修改後可用資料完整性檢查(確認每題只有一個正解、案例答案存在等):

```bash
node check.js
```

## 重要聲明

- 教材中的**數值(扭力、間隙、保養週期、電壓)是常見範圍,用來建立數量級直覺**。實際作業一律以「該車型、該年份」的原廠維修手冊為準。
- 電動機車的**高壓電池、控制器內部、高壓線束**不是新手能自行處理的範圍,請交給原廠或受過訓練的專業人員。
- 模擬無法取代手感與現場經驗,請在師傅指導下進行第一次實車作業。
